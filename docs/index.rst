python-traceprint
=================

Readable print and logging traces for scripts and development. Install the
``python-traceprint`` distribution and import ``traceprint``. Python 3.12 or later
is required; there are no runtime dependencies. The public API is alpha.

This documentation describes version 0.1.2. The
library is licensed under MIT. Importing it does not intercept process streams.
