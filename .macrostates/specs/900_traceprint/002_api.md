# API

Traceprint's public API is small and explicit. Signatures below specify argument
positions, keyword-only parameters and defaults; ordinary Python exceptions are
used rather than a separate error type. Values must satisfy the annotated text,
stream and logging contracts; constructors do not perform general type validation.

## Public imports

The root exports exactly these names through `__all__`, in this order:

```text
DARK_GREY, DEFAULT_COLORS, RESET, LoggerMixin, Tracer,
TracerFileHandler, TracerHandler, trace, tracer
```

The color values are owned by [Formatting](003_formatting.md#color-values).
`Span` and the logger proxy are returned objects, not package-root exports.
There is no required `traceprint.__version__`; distribution version lookup uses
`importlib.metadata.version("python-traceprint")`.

## Tracer construction

All constructor arguments are keyword-only:

```python
Tracer(
    *,
    use_colors: bool | None = None,
    use_tabulation: bool = False,
    color_scheme: list[str] | None = None,
    metacolor: str | None = DARK_GREY,
    print_transitions: bool = False,
    filter_levels: range | Iterable[int] | Callable[[int], bool] | None = None,
    start_enabled: bool = True,
    output_format: str = DEFAULT_OUTPUT_FORMAT,
    timestamp_format: str = "%Y-%m-%d %H:%M:%S",
    stream: TextIO | None = None,
    error_stream: TextIO | None = None,
    intercept_stdout: bool = False,
    intercept_stderr: bool = False,
)
```

`DEFAULT_OUTPUT_FORMAT` denotes the exact literal specified in
[Formatting](003_formatting.md#format-fields), not a new root export.

| Option | Meaning |
| --- | --- |
| `use_colors` | `None` detects the sink's TTY status; explicit booleans select color output. |
| `use_tabulation` | Enable four spaces per depth, with placement independent of color output. |
| `color_scheme` | Ordered ANSI foreground strings; `None` or an empty list selects `DEFAULT_COLORS`. |
| `metacolor` | Color metadata separately; a falsey value selects whole-line depth coloring. |
| `print_transitions` | Emit the context entry/exit messages specified in [Contexts](005_contexts.md). |
| `filter_levels` | Allowed depths or a predicate returning truthy for allowed depths. |
| `start_enabled` | Initial formatting/depth-tracking state. |
| `output_format` | Python format string containing the supported fields. |
| `timestamp_format` | UTC `strftime` format. |
| `stream` | Output sink, defaulting to current stdout; preserve whether it was explicitly supplied. |
| `error_stream` | Accepted compatibility parameter; it does not create a separate stderr output route. |
| `intercept_stdout`, `intercept_stderr` | Explicit construction-time installation requests, both false by default. |

Construction initializes `depth = 0`, `labels = []`, an unlocked state, no active
interception captures, no attached file mirrors and a fresh line state. Read the
performance clock once and use that value as both the start and last-format time.
Resolve colors before optional installation; installation does not redetect TTY
status or reset timing, labels or line state.

Use the supplied stream when present in ordinary use, otherwise current stdout.
The alpha's falsey-stream selection nuance is documented in the
[compatibility annex](annex_observed-compatibility.md#stream-and-installation-edges).
A supplied nonempty palette and the default palette are shared by reference,
not copied. Keep a palette nonempty after selection.

## Tracer state and operations

Readable/mutable public configuration attributes are `use_colors`,
`use_tabulation`, `color_scheme`, `metacolor`, `print_transitions`, `filter_levels`,
`output_format` and `timestamp_format`. `depth` and `labels` expose current context;
prefer balanced context operations to direct mutation. `enabled` is read-only.
Depth and labels are separate mutable values; assigning one does not automatically
reconcile the other. Configuration changes do not reset clocks or line state.

| Signature | Result and owner |
| --- | --- |
| `enabled -> bool` | Current enabled flag. |
| `install(*, stdout: bool = True, stderr: bool = False) -> None` | Explicit stream capture/replacement; [Interception](004_interception.md#installation). |
| `uninstall() -> None` | Restore captured streams and clear installation flags. |
| `enable() -> None`, `disable() -> None` | Set formatting/depth-tracking state without resetting context or clocks. |
| `lock() -> None`, `unlock() -> None` | Set depth-mutation lock without changing existing context. |
| `configure(**kwargs) -> None` | Ordered configuration updates described below. |
| `format(message: str) -> str` | Format without output; advances timing; [Formatting](003_formatting.md). |
| `write(data: str) -> int` | Immediate fragment output; returns input length; [Interception](004_interception.md#writing-fragments). |
| `flush() -> None` | Flush the sink and each mirror without ending a line. |
| `push(label: str | None = None) -> None` | Manual depth entry; [Contexts](005_contexts.md#manual-push-and-pop). |
| `pop(label: str | None = None) -> None` | Manual depth exit, safe at depth zero. |
| `span(label: str) -> Span` | Return a synchronous context manager; [Contexts](005_contexts.md#spans). |
| `add_file_handler(handler: TracerFileHandler) -> None` | Append a mirror in attachment order. |
| `remove_file_handler(handler: TracerFileHandler) -> None` | Remove its first matching attachment; missing attachment is a no-op. |

There is no return-value aggregation from sink/mirror writes and no implicit
closing of a sink or attached handlers. See [Logging](006_logging.md) for handler
ownership and failure behavior.

## Configuration order

Apply one `configure` call in this order:

1. If either interception key is supplied, derive both desired flags. Missing
   flags retain their current installed state; supplied values use `bool(value)`.
   Uninstall the current captures, then install the derived combination.
2. If `use_colors` is supplied, `None` redetects the current sink's TTY status;
   any other value uses `bool(value)`.
3. If `color_scheme` is supplied, select the provided sequence or default palette
   using its truthiness.
4. Assign remaining keys in caller order when the tracer already has that
   attribute. Otherwise raise `AttributeError("Tracer has no attribute NAME")`.

This is not a constructor replay. Names such as `stream`, `error_stream` and
`start_enabled` are not public configuration attributes; use lifecycle methods
for enabled state and construction for a sink. A read-only attribute assignment
raises normal `AttributeError`. Earlier updates are retained if a later one
fails. The permissive alpha handling of private/method attributes is an
[observation](annex_observed-compatibility.md#configuration-and-mutable-state),
not an additional supported configuration surface.

## Global tracer

Create one global convenience `tracer` when the runtime module first imports,
using ordinary constructor defaults. Root imports refer to this same object.
Import alone must not replace stdout/stderr, open logging files, attach root
logging handlers or configure the root logger. Environment labels are the only
specified import-time configuration beyond constructor defaults.

## Environment variables

Read `TRACEPRINT_INITIAL_LABELS` once at import time, defaulting to the empty
string. Strip the complete value; split it on `/`; strip each component and
discard empty components. Push each remaining component in order on the global
tracer. This sets both labels and depth; it does not install the tracer.

For example, `" / job // load / "` produces labels `["job", "load"]` and depth 2.
Explicit new tracer instances do not read this variable. Later environment edits
do not mutate the existing global instance. There are no other Traceprint-owned
environment variables.

## Context and logging interfaces

```python
trace(_func: Callable[..., Any] | None = None, *,
      label: str | None = None, force: bool = False,
      tracer_instance: Tracer | None = None) -> Callable[..., Any]

TracerHandler(level: int = logging.NOTSET, *,
              tracer_instance: Tracer | None = None)

TracerFileHandler(filename: str | os.PathLike[str], mode: str = "a",
                  level: int = logging.NOTSET, encoding: str = "utf-8", *,
                  tracer_instance: Tracer | None = None)

LoggerMixin(*, verbose: bool = True, logging_level: int = logging.INFO,
            logging_passthrough: bool = False, lazy_init: bool = False)
```

`trace` supports bare and parameterized decorator forms. Its target selection,
transitions, result/exception behavior and `force` boundary are owned by
[Contexts](005_contexts.md#function-decorator).

Both handlers subclass `logging.Handler` and support standard levels, formatters,
filters and `handle` behavior. They implement `emit(record: logging.LogRecord)
returning `None`. File handlers additionally expose `write(data: str) -> None`,
`flush() -> None` and `close() -> None`, and the filename/mode/encoding/tracer/stream
attributes described in [Logging](006_logging.md#file-handler).

`LoggerMixin.logger` returns a standard logger; `LoggerMixin.log` returns the same
instance's verbosity-gated proxy. The proxy supports `log(level, msg, *args,
**kwargs)`, `debug`, `info`, `warning`, `error` and `critical`, all returning `None`.
No proxy `exception` or `warn` method is required. Use `.logger` for the full
standard logging interface. Initialization and shared-logger effects are owned
by [Logging](006_logging.md#logger-mixin).
